# Third-party design references

This project has been informed by existing parametric pegboard work, particularly:

- **PEGSTR / Pegboard Wizard**, by Marius Gheorghescu / MGX3D
  - https://github.com/MGX3D/pegstr
  - The upstream README identifies PEGSTR as Creative Commons Attribution-NonCommercial.
  - A user-modified PEGSTR-derived design provided a known-working mechanical reference for the hook/locator behavior.

- **Pegmixer**, by stockholmux and related OpenSCAD work
  - https://github.com/stockholmux/pegmixer
  - https://github.com/diplodocuslongus/pegmixer_openscad
  - Useful reference for declarative holder sizing and separating pegboard mounting from tool-holder geometry.

Do not copy third-party source into this repository without preserving the applicable attribution and license requirements. The long-term goal is a self-contained implementation expressed specifically for this project.
